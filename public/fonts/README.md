Khmer OS Siemreab font files

This folder should contain the Khmer OS Siemreab font files used by the app.

Expected files (place them here):
- KhmerOSSiemreab-Regular.woff2
- KhmerOSSiemreab-Regular.woff
- KhmerOSSiemreab-Bold.woff2
- KhmerOSSiemreab-Bold.woff

You can obtain these files from a trusted source or the font vendor. After placing them here, the site will use the Khmer OS Siemreab font automatically.

If you prefer to use a different Khmer font (e.g., Noto Sans Khmer), update the @font-face src paths in `app/globals.css` accordingly.
